# 🚀 InAmigos Foundation - AI Powered Social Impact Platform

An AI-generated, fully responsive, and modern social impact web platform built for **InAmigos Foundation** as part of Task 3 during the Web Development Internship.

🌐 **Live Demo:** [InAmigos Foundation Web Platform](https://inamigos-foundation-website-ten.vercel.app/)

---

## 📌 Project Overview

This platform is engineered to showcase the core social mission, ongoing initiatives, live metrics, and transparency accreditations of InAmigos Foundation. Designed with a modern UI/UX focus, fast performance, and responsive layout across desktop and mobile devices.

---

## ✨ Key Features & Architecture

- 🎯 **Hero Section & Live Metrics:** High-contrast layout displaying live impact statistics (50,000+ Beneficiaries, 28+ States, 200+ Volunteers).
- 💡 **Core Initiatives Grid:** Structured card layouts for:
  - **Project Seva:** Food aid & essential distribution drives.
  - **Project Bachpanshala:** Quality education for street children.
  - **Project Jeev:** Animal rescue & emergency medical care.
  - **Project Udaan:** Women empowerment & skill development.
- 🛡️ **Transparency & Accreditation Portal:** Verification badges for NITI Aayog, 80G/12A, ISO 9001:2015, and CSR-1 registration.
- 📬 **Interactive Volunteer Portal:** Seamless contact and volunteer onboarding interface.
- 📱 **Fully Responsive:** Engineered using Flexbox and CSS Grid for optimal cross-device performance.

---

## 🛠️ Tech Stack & Tools

- **Frontend:** HTML5, Modern CSS3 (Grid & Flexbox), JavaScript
- **AI Tooling:** Prompt-engineered layout generation
- **Deployment:** Vercel Global Edge Network
